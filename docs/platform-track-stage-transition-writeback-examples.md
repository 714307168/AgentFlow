# 平台专项阶段切换回写示例

更新时间：2026-04-21

这份文档不再讲完整模板，而是直接给出“平台专项从一个阶段切到下一个阶段时，路线图里该怎么回写”的短样例。

它适合解决这几个问题：

- 平台专项并不是一次性完成，而是在规划、收口、验收、首发、观察之间切换，但路线图里缺少短样例
- 已经有平台专项收口摘要和平台专项路线图回写示例，但缺少更明确的“阶段切换”语气
- 想把 `mac / iOS / 小程序` 这类平台节点的阶段变化稳定控制在摘要级别，不回到过程说明

建议配合：

- [平台专项收口摘要模板](./platform-track-closure-summary-template.md)
- [平台专项路线图回写示例](./platform-track-roadmap-writeback-examples.md)
- [平台首发摘要模板](./platform-first-release-summary-template.md)

## 1. 使用方式

推荐顺序：

1. 先在平台专项文档或收口摘要里保留完整边界、风险和动作。
2. 再从完整内容里抽 2 到 4 行，回写到路线图。
3. 路线图里只保留“从哪个阶段切到哪个阶段、切换依据是什么、下一步是什么”，不要重新写成长段设计说明。

路线图里最好让人一眼看出：

- 当前从哪个阶段切到了哪个阶段
- 切换依据是范围确认、验收完成，还是首发准备完成
- 当前明确不做或延后的范围是什么
- 下一步是实现、验收、首发还是观察

## 2. 规划完成 -> 首发准备完成

### 2.1 mac

~~~text
- R-mac-first 从规划完成切到首发准备完成：
  - 首发范围已收口到构建、更新、数据目录、权限和回滚路径
  - 暂不扩展通用自动化打磨和更大范围的桌面特性
  - 下一步进入签名、公证和首发验收
~~~

### 2.2 iOS Safe Track

~~~text
- R-ios-safe-track 从规划完成切到 Safe Track 准备完成：
  - 首发边界已收敛到登录、项目列表、消息查看、轻量回复和文件接收
  - 不按安卓镜像版推进，也不承接完整远控终端能力
  - 下一步先补协议复用和首发验收
~~~

## 3. 边界确认 -> 首发待验证

### 3.1 iOS Safe Track

~~~text
- R-ios-safe-track 从边界确认切到首发待验证：
  - Safe Track 范围与延后范围已明确
  - 当前重点转向弱网恢复、审核约束和协议复用核查
  - 下一步通过首发验收后再决定是否扩大边界
~~~

### 3.2 小程序 Lite

~~~text
- R-mini-lite 从 Lite 边界确认切到首发待验证：
  - 轻入口能力已收口到查看、快速回复、状态确认和文件接收
  - 不承担重设置、大缓存和完整实时控制角色
  - 下一步补轻量验收和交互细节核查
~~~

## 4. 首发完成 -> 首发后观察

### 4.1 mac

~~~text
- R-mac-first 从首发完成切到首发后观察：
  - 首个可安装版本已对外可用
  - 当前先稳安装、启动、同步和更新链路，不立即继续扩边界
  - 下一步按观察结论决定是否补边界或准备热修
~~~

### 4.2 小程序 Lite

~~~text
- R-mini-lite 从首发完成切到首发后观察：
  - Lite 轻入口版本已完成对外首发
  - 当前继续维持轻入口定位，先观察查看、回复和重连反馈
  - 下一步根据观察结果决定是否继续打磨交互
~~~

## 5. 观察完成 -> 继续补边界

### 5.1 mac

~~~text
- R-mac-first 从首发后观察切到继续补边界：
  - 首轮观察已完成，当前版本可继续维持
  - 后续继续补签名自动化、安装体验和更新链路细节
  - 下一步按增量能力继续验收和分批发版
~~~

### 5.2 小程序 Lite

~~~text
- R-mini-lite 从首发后观察切到继续补轻入口边界：
  - Lite 主链路已验证可用
  - 当前继续优化状态刷新、快速回复和重连反馈
  - 下一步跟随轻量验收结果决定是否继续补交互细节
~~~

## 6. 不推荐写法

不要在路线图里继续写这种又长又模糊的段落：

~~~text
平台专项目前已经推进到了下一阶段，后面会根据情况继续做验证、补边界和观察，之后再决定要不要继续往后推。
~~~

原因：

- 看不出到底是从哪个阶段切到哪个阶段
- 看不出当前阶段切换的依据是什么
- 看不出下一步是验收、首发还是观察
- 很容易把路线图重新写成过程汇报

## 7. 当前结论

后续平台专项阶段切换回写时，优先复用这份文档里的短样例，把阶段变化、切换依据和下一步动作压成路线图语气，避免总览继续膨胀。
