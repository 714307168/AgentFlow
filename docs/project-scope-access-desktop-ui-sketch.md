# 项目级授权桌面端 UI 草图

更新时间：2026-04-18
关联方案：[`docs/project-scope-access-mvp.md`](./project-scope-access-mvp.md)

## 1. 目标

这份文档不再讨论为什么做项目级授权，只回答桌面端授权管理页应该怎么摆、怎么填、怎么处理异常状态。

首期目标：

- 在设置页里能直接看到“授权管理”
- 新建/编辑授权时能同时勾选账号、项目范围、能力包
- 列表页能快速判断授权是否生效、是否过期、是否已撤销
- 不把授权交互做成复杂工单系统，只保留最小可用管理面

## 2. 入口位置

建议入口：

- 设置页一级分组：`连接与账号`
- 子卡片：`远程授权管理`
- 卡片摘要：
  - 当前桌面节点名称
  - 当前有效授权数
  - 最近变更时间
  - `新建授权` 按钮

当节点不是拥有者或当前账号无管理权限时：

- 列表只读
- `新建授权` 置灰
- 顶部显示“当前账号无授权管理权限”

## 3. 列表草图

```text
+--------------------------------------------------------------+
| 远程授权管理                                   [新建授权]    |
+--------------------------------------------------------------+
| 搜索账号 / 项目                             状态: 全部 v     |
+--------------------------------------------------------------+
| 协作者      设备范围   项目范围     能力包       状态   操作 |
| 张三        全设备     3 个项目      collaborate  生效   编辑 |
| 李四        android-2  全部项目      observe      过期   查看 |
| 王五        全设备     2 个项目      operate      已撤销 查看 |
+--------------------------------------------------------------+
| 选中行展开摘要：                                            |
| - 项目: A、B、C                                              |
| - 文件下载: 允许                                             |
| - 诊断查看: 禁止                                             |
| - 过期时间: 永久 / 2026-04-20 18:00                          |
| - 备注: 现场联调                                             |
+--------------------------------------------------------------+
```

列表最少字段：

- 协作者账号
- 目标设备范围
- 项目范围摘要
- 能力包
- 状态
- 更新时间

状态优先级：

1. `已撤销`
2. `已过期`
3. `即将过期`
4. `生效中`

项目范围摘要规则：

- `all_projects` 显示“全部项目”
- `selected_projects` 显示“n 个项目”
- 悬停或展开行再看具体项目名，避免列表挤压

## 4. 新建/编辑弹窗草图

```text
+------------------------------------------------------------------+
| 新建授权                                                    [X]   |
+------------------------------------------------------------------+
| 协作者账号 *                                                    |
| [ 选择账号................................................. ]    |
|                                                                  |
| 设备范围                                                         |
| (•) 该账号下全部设备   ( ) 指定设备                               |
| [ 选择设备................................................. ]    |
|                                                                  |
| 项目范围 *                                                       |
| ( ) 全部项目                                                     |
| (•) 指定项目                                                     |
| [ 搜索项目................................................. ]    |
| [ ] 项目 A                                                       |
| [ ] 项目 B                                                       |
| [ ] 项目 C                                                       |
| [ ] 项目 D                                                       |
|                                                                  |
| 能力包 *                                                         |
| ( ) observe   (•) collaborate   ( ) operate   ( ) admin          |
|                                                                  |
| [x] 允许文件下载                                                 |
| [ ] 允许查看诊断                                                 |
|                                                                  |
| 过期时间                                                         |
| [ 永久有效 v ]  或  [ 2026-04-20 18:00 ]                         |
|                                                                  |
| 备注                                                             |
| [ 现场调试 / 远程部署协作................................. ]      |
|                                                                  |
|                              [取消] [保存授权]                   |
+------------------------------------------------------------------+
```

交互规则：

- 新建和编辑共用一套表单
- 选择 `指定项目` 后，项目列表必须可搜索、可滚动、可全清
- 编辑态回填原有项目勾选，不允许 silently reset
- `observe` 时默认关闭发送/下载/诊断类开关
- `admin` 不自动强开高风险开关，仍显式展示当前勾选结果

## 5. 表单校验

必校验项：

- 协作者账号不能为空
- `selected_projects` 时至少选中 1 个项目
- 指定设备模式下必须选中设备
- 过期时间若存在，必须大于当前时间

保存前端提示文案建议：

- “请先选择协作者账号”
- “请至少勾选 1 个项目”
- “指定设备授权时必须选择目标设备”
- “过期时间必须晚于当前时间”

## 6. 状态与异常处理

### 6.1 行状态

- `生效中`：绿色标签
- `即将过期`：黄色标签，阈值建议 24h
- `已过期`：灰色标签，不允许再编辑项目范围外的联动判断
- `已撤销`：红色或灰色标签，只保留查看

### 6.2 空态

- 无授权记录：
  - 文案：“还没有给协作者分配项目范围”
  - 操作：`新建第一条授权`

### 6.3 保存失败

- 账号不存在：提示并保留表单内容
- 项目已失效：提示后要求重新选择项目
- 服务端返回 401/403：提示“当前账号无权管理该节点授权”
- 并发修改冲突：提示“授权已被其他端更新，请刷新后重试”

### 6.4 撤销确认

建议二次确认弹窗：

- 标题：`确认撤销该授权？`
- 说明：`撤销后，对方刷新后将无法继续访问这些项目。`
- 按钮：`取消` / `确认撤销`

## 7. 分辨率与滚动约束

首期先守住可用性，不追求复杂响应式：

- 授权列表区域最小高度建议 `420px`
- 项目多选列表内部独立滚动，不挤压整个弹窗
- 弹窗内容区滚动，底部操作按钮固定
- 1366 宽度下保证项目列表、能力包和开关区不换行挤爆

## 8. 实现拆分建议

为避免继续堆大文件，桌面端实现建议拆成：

- `authorization-list-pane`
- `authorization-form-modal`
- `authorization-project-picker`
- `authorization-status-badge`

这样后续补测试时，也能分别覆盖列表渲染、回填、校验和状态文案。
