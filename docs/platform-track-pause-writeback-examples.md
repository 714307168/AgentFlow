# 平台专项阶段暂停与延后推进回写示例

更新时间：2026-04-21

这份文档不再讲完整模板，而是直接给出“平台专项暂时暂停、延后推进或主动降优先级时，路线图里该怎么回写”的短样例。

它适合解决这几个问题：

- 平台专项并不是一直线性推进，中间常会因为风险、依赖、资源或优先级变化而暂停，但路线图里缺少短样例
- 已经有阶段切换、阶段收口和风险处理示例，但缺少更明确的“暂停/延后推进”语气
- 想把 `mac / iOS / 小程序` 这类平台节点的暂停结论稳定控制在摘要级别，不回到长段解释

建议配合：

- [平台专项阶段切换回写示例](./platform-track-stage-transition-writeback-examples.md)
- [平台专项阶段完成短收口示例](./platform-track-stage-closure-writeback-examples.md)

## 1. 使用方式

推荐顺序：

1. 先在平台专项文档或风险/收口文档里保留完整原因、边界和后续动作。
2. 再从完整内容里抽 2 到 4 行回写到路线图。
3. 路线图里只保留“为什么暂停、当前保留什么、明确不继续做什么、后面什么时候再看”，不要把现场讨论过程整段搬进去。

路线图里最好让人一眼看出：

- 当前是主动暂停、被动延后，还是降优先级排队
- 当前仍维持的边界或可用状态是什么
- 哪些范围明确不在本轮继续推进
- 下一步是等依赖、等热修结束，还是等下一轮计划重启

## 2. 因风险暂停示例

### 2.1 mac

~~~text
- R-mac-first 当前暂停继续推进：
  - 先稳签名、公证和安装链路，暂停继续补更深桌面能力
  - 当前可安装范围继续维持，但不在本轮扩大平台边界
  - 下一步等观察和热修结论稳定后再恢复推进
~~~

### 2.2 iOS Safe Track

~~~text
- R-ios-safe-track 当前延后推进：
  - 审核约束、后台限制和弱网恢复风险尚未收口
  - 先维持 Safe Track 窄边界，不继续追加新能力
  - 下一步等首轮风险处理完成后再决定是否重启扩边界
~~~

## 3. 因依赖未就绪延后示例

### 3.1 小程序 Lite

~~~text
- R-mini-lite 当前延后推进：
  - 轻入口主链路已明确，但依赖的交互细节和能力复用仍未收齐
  - 当前先保留 Lite 定位，不继续补更深能力
  - 下一步等依赖接口与轻量验收准备好后再恢复推进
~~~

### 3.2 iOS Safe Track

~~~text
- R-ios-safe-track 当前延后推进：
  - 协议复用和首发验收条件尚未齐备
  - 当前只保留已确认的 Safe Track 范围，不进入更大范围实现
  - 下一步等跨端基础能力对齐后再继续推进
~~~

## 4. 因优先级调整降级示例

### 4.1 mac

~~~text
- R-mac-first 当前降级排队：
  - 本轮优先级先让位于 Android 稳定性和发布可靠性收口
  - 当前首发准备结论继续保留，不在这一轮继续补实现细节
  - 下一步等主链路稳定后再回到桌面双平台扩展
~~~

### 4.2 小程序 Lite

~~~text
- R-mini-lite 当前降级排队：
  - 当前先让位于桌面与移动主链路的稳定性问题处理
  - Lite 边界结论继续有效，但不在本轮继续补交互打磨
  - 下一步等主链路专项收口后再恢复轻入口计划
~~~

## 5. 主动收窄范围并延后示例

### 5.1 iOS Safe Track

~~~text
- R-ios-safe-track 当前主动收窄并延后：
  - 继续只保留登录、项目列表、消息查看和轻量回复
  - 文件接收之外的更深能力不再放在本轮推进
  - 下一步先稳现有边界，再决定是否开新一轮专项
~~~

### 5.2 mac

~~~text
- R-mac-first 当前主动收窄并延后：
  - 只保留首发必须的构建、更新和安装链路
  - 通用包优化与更深自动化不在本轮继续推进
  - 下一步待首发链路稳定后再单独重开体验专项
~~~

## 6. 不推荐写法

不要在路线图里继续写这种又长又模糊的段落：

~~~text
平台专项这边先缓一缓，后面看情况再继续，具体什么时候恢复推进以及现在到底保留哪些范围，后续再说。
~~~

原因：

- 看不出是暂停、延后还是降优先级
- 看不出当前仍保留的边界是什么
- 看不出哪些范围明确不继续做
- 看不出恢复推进的前提条件

## 7. 当前结论

后续平台专项如果进入暂停或延后推进状态，优先复用这份文档里的短样例，把暂停原因、保留边界和恢复条件压成路线图语气，避免总览继续膨胀。
