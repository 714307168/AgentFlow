# 平台专项验收通过但暂不首发的短回写示例

更新时间：2026-04-22

这份文档不再讲完整模板，而是直接给出“平台专项已经验收通过，但因为节奏、风险控制、依赖窗口或发布策略，当前决定暂不首发时，路线图里该怎么回写”的短样例。
它适合解决这几个问题：

- 平台专项有时已经通过验收，但并不会立刻发版，路线图里缺少明确的“验收通过但暂不首发”语气
- 已经有首发延期和验收未通过样例，但缺少“已经过线，只是暂不发”的写法
- 想把 mac / iOS / 小程序 这类平台节点当前为什么暂不首发、保留什么边界和后续发布条件稳定控制在摘要级别

## 1. 使用方式

推荐顺序：
1. 先在平台专项文档、验收清单或发版计划里写清楚哪些验收已通过、为什么暂不发、当前保留哪些范围。
2. 再从完整内容里抽 2 到 4 行回写到路线图。
3. 路线图里只保留“验收已过、暂不首发的原因、当前保留边界、何时再进入发布判断”，不要把完整验收记录整段搬进去。

路线图里最好让人一眼看出：

- 当前不是没过验收，而是主动暂缓首发
- 已通过的验收范围是什么
- 暂不首发的主因是节奏、风险、依赖还是发布策略
- 后续何时会重新进入首发判断

## 2. 因发布节奏主动暂不首发

### 2.1 mac

~~~text
- R-mac-first 当前验收已通过但暂不首发：
  - 安装、更新和回退链路验收已经过线，当前先不抢首发窗口
  - 当前继续维持最小可发布主链路，不并回更大桌面体验范围
  - 下一步按发版节奏和联动窗口再重新判断是否首发
~~~

### 2.2 小程序 Lite

~~~text
- R-mini-lite 当前验收已通过但暂不首发：
  - Lite 最小主链路验收已经通过，当前先不单独抢发布窗口
  - Lite 定位继续保持不变，不借机扩到更重交互
  - 下一步等轻入口发布节奏和联动条件对齐后再决定是否首发
~~~

## 3. 因风险控制暂不首发

### 3.1 iOS Safe Track

~~~text
- R-ios-safe-track 当前验收已通过但暂不首发：
  - Safe Track 验收已过，但为了避免在边界仍敏感时直接对外首发，当前先观察
  - 当前继续只保留登录、项目列表、消息查看和轻量回复边界
  - 下一步等审核和弱网信号继续稳定后再决定首发时间
~~~

### 3.2 mac

~~~text
- R-mac-first 当前验收已通过但暂不首发：
  - 主链路已过验收，但当前先保守处理，不把仍有观察风险的版本直接推向首发
  - 当前继续维持首发窄边界，不扩体验增强范围
  - 下一步按观察结果决定是否进入正式首发
~~~

## 4. 因依赖窗口或联动发布策略暂不首发

### 4.1 小程序 Lite

~~~text
- R-mini-lite 当前验收已通过但暂不首发：
  - 轻入口主链路已过验收，但当前要等联动发布窗口，不单独发
  - Lite 范围继续维持，不因为验收通过就扩大产品定位
  - 下一步等相关端和联动节奏准备好后再推进首发
~~~

### 4.2 iOS Safe Track

~~~text
- R-ios-safe-track 当前验收已通过但暂不首发：
  - Safe Track 范围已完成验收，但当前要等审核窗口和配套链路时机
  - 当前不增加任何新边界，继续保持已确认的轻量可用范围
  - 下一步等发布窗口和审核条件对齐后再进入首发判断
~~~

## 5. 验收通过后先收口再决定是否发

### 5.1 mac

~~~text
- R-mac-first 当前验收已通过但暂不首发：
  - 当前先把验收结论收口到专项文档，不立即对外发版
  - 已通过范围继续有效，但更大桌面能力不进入这轮首发计划
  - 下一步根据发版窗口决定是直接首发还是并入下一轮计划
~~~

### 5.2 iOS Safe Track

~~~text
- R-ios-safe-track 当前验收已通过但暂不首发：
  - 当前先确认 Safe Track 验收通过后的观察边界，不直接进入对外首发
  - 延后范围继续冻结，不因为验收通过自动扩边界
  - 下一步根据审核与联动节奏决定是否进入首发阶段
~~~

## 6. 不推荐写法

不要在路线图里继续写这种又长又模糊的段落：

~~~text
这个平台现在应该算已经差不多可以发了，不过后面暂时还不准备马上发，具体现在到底算不算已经通过、为什么先不发、什么时候再决定发不发，后面再统一看。
~~~

原因：

- 看不出是不是已经通过验收
- 看不出暂不首发的原因是什么
- 看不出当前保留的边界是否继续有效
- 看不出什么时候会重新进入发布判断

## 7. 当前结论

后续平台专项如果已经验收通过、但当前决定暂不首发，优先复用这份文档里的短样例，把已通过范围、暂缓原因和再次进入发布判断的条件压成路线图语气，避免总览继续膨胀。
