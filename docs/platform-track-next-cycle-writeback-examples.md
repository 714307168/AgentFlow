# 平台专项并入新一轮计划的短回写示例

更新时间：2026-04-21

这份文档不再讲完整模板，而是直接给出“平台专项没有单独结束，而是并入下一轮计划继续推进时，路线图里该怎么回写”的短样例。
它适合解决这几个问题：

- 平台专项经常会从单独专题转成下一轮常规迭代的一部分，但路线图里缺少明确的“并入新一轮计划”语气
- 已经有收口、切换、暂停和重启样例，但缺少“并入下一轮继续推进”的收束写法
- 想把 mac / iOS / 小程序 这类平台节点的延续关系、保留边界和新一轮重点稳定控制在摘要级别

## 1. 使用方式

推荐顺序：
1. 先在平台专项文档或收口摘要里保留本轮结论、保留边界和下一轮目标。
2. 再从完整内容里抽 2 到 4 行回写到路线图。
3. 路线图里只保留“本轮收到哪、哪些能力并入下一轮、哪些边界继续冻结、下一轮主攻什么”，不要再把旧专项整段重讲一遍。

路线图里最好让人一眼看出：

- 这是专项并入新一轮计划，不是原地继续写旧任务
- 哪些能力和结论被带入下一轮
- 哪些边界继续保持冻结或轻量定位
- 新一轮主线是发版、验收、补边界还是转常规维护

## 2. 首发准备并入下一轮发版计划

### 2.1 mac

~~~text
- R-mac-first 本轮已并入下一轮发版计划：
  - 首发准备结论继续有效，下一轮直接承接签名、安装和更新链路发版
  - 当前不把更深桌面能力扩展并入这一轮，继续保持首发窄边界
  - 下一步按单端发版验收和首发观察模板继续推进
~~~

### 2.2 iOS Safe Track

~~~text
- R-ios-safe-track 本轮已并入下一轮计划：
  - Safe Track 边界确认和轻量链路结论继续沿用
  - 下一轮只承接首发待验证和审核约束压实，不扩到完整远控能力
  - 下一步按首发前验证和观察路径继续推进
~~~

## 3. 首发后观察并入下一轮补边界

### 3.1 mac

~~~text
- R-mac-first 已并入下一轮补边界计划：
  - 首发后观察结论已收口，当前版本可继续维持
  - 下一轮承接安装体验、自动更新和回滚链路打磨，不重开大范围平台改造
  - 下一步按增量验收结果决定是否再开新阶段
~~~

### 3.2 小程序 Lite

~~~text
- R-mini-lite 已并入下一轮轻入口打磨计划：
  - Lite 首发观察结论继续有效，轻入口定位保持不变
  - 下一轮继续补状态刷新、快回体验和文件接收细节，不承接完整实时控制
  - 下一步按轻量验收和发布反馈决定是否继续补边界
~~~

## 4. 风险收口后并入常规维护

### 4.1 iOS Safe Track

~~~text
- R-ios-safe-track 已并入下一轮常规维护：
  - 首轮风险和边界问题已收口，Safe Track 主链路可转入常规维护节奏
  - 下一轮只跟随主链路补兼容性和弱网恢复，不单开更大平台专项
  - 下一步通过常规版本验证继续观察是否需要重新拉起专项
~~~

### 4.2 mac

~~~text
- R-mac-first 已并入下一轮常规桌面迭代：
  - 首发相关链路已基本稳定，后续随桌面主线版本继续维护
  - 当前不再单列更大平台专项，只保留必要的更新和安装链路修正
  - 下一步按桌面版常规发版节奏持续观察和补丁修复
~~~

## 5. 保留轻量定位并入下一轮优化

### 5.1 小程序 Lite

~~~text
- R-mini-lite 已并入下一轮轻量优化计划：
  - Lite 边界和定位继续保留，不转向完整移动控制端设计
  - 下一轮只承接轻入口体验、同步精度和弱网反馈优化
  - 下一步按轻量验收结果决定是否继续补细节，不扩产品定位
~~~

### 5.2 iOS Safe Track

~~~text
- R-ios-safe-track 已并入下一轮轻量验证计划：
  - Safe Track 结论继续有效，下一轮仍按轻量可用优先
  - 文件外更深交互和更大缓存能力继续冻结，不进入本轮范围
  - 下一步先压实现有边界，再决定是否值得开启新专项
~~~

## 6. 不推荐写法

不要在路线图里继续写这种又长又模糊的段落：

~~~text
这个平台专项后面会放到下一轮里一起继续做，具体算不算还在专项里、下一轮到底接哪些内容、哪些能力是不是还保留，后面再统一看情况安排。
~~~

原因：

- 看不出旧专项和新一轮计划之间的承接关系
- 看不出哪些能力被明确带入下一轮
- 看不出哪些边界继续冻结
- 看不出下一轮主攻的是发版、补边界还是常规维护

## 7. 当前结论

后续平台专项如果不再单独展开、而是并入下一轮计划继续推进，优先复用这份文档里的短样例，把承接关系、保留边界和下一轮重点压成路线图语气，避免总览继续膨胀。
