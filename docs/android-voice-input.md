# Android 语音输入

## 使用方式

Android 1.2.81（versionCode 165）起，中文离线识别模型随 APK 分发。
没有系统语音识别服务的手机也不需要首次联网下载语音包。

在项目聊天或协作组聊天点击麦克风：

1. 首次点击申请麦克风权限，授权后继续本次操作。
2. 有可用的系统识别界面时使用系统服务；Android 11 以上声明对应的 package query。
3. 没有系统服务时，弹出准备状态，将 APK 内置模型解压到应用私有目录。
4. 显示“请说话”后开始说普通话，界面显示识别中的文本。
5. 停顿后自动结束，或点击“说完了”；最长录音 30 秒。
6. “转文字”追加到输入框，“直接发送”使用现有的项目或群组消息发送流程。

取消、返回或应用进入后台会中止离线录音。取消后的旧回调不能再次发送消息。
准备失败与麦克风无法打开分别提示；详细错误记入应用日志。
语音识别可以离线完成，向远程项目发送消息仍需要服务器连接。

## 打包与缓存

- 模型：Alpha Cephei 的 `vosk-model-small-cn-0.22`，Apache-2.0。
- 原始压缩包约 42 MiB，解压约 65 MiB；APK 会比旧版增加约 42 MiB。
- `android-app/gradle/offline-voice.gradle` 在构建时获取官方模型，镜像仅作构建时备用。
- SHA-256 固定为 `3af8b0e7e0f835ae9d414ce5df580237a3cfb08d586c9fbbb0f7ff29ad5b14ba`。
- 压缩包缓存于 Gradle 用户缓存，复制至构建生成的 assets。仓库不提交模型或 APK。
- Gradle 的 generated assets API 将准备任务接入 Debug、Release 和 lint。
- 下载失败或校验不符直接使构建失败，避免发布缺少语音包的 APK。
- 设备端只读取 assets；校验、解压和 native 模型加载均在后台执行。
- 完整安装标记配合必要模型文件检查，避免把不完整的旧目录当作可用模型。
- 解压过程保留大小限制、路径校验和取消检查。临时文件在失败、取消后清理。
- 模型复用原有私有目录，并排除在云备份和设备迁移之外。

## 验证

使用 JDK 17：

```powershell
cd android-app
.\gradlew.bat :app:testDebugUnitTest :app:assembleRelease --no-daemon
```

模型和依赖缓存后可以追加 `--offline` 构建。
单元测试会安装与 APK 相同的真实模型压缩包，覆盖首次安装、缓存复用、
损坏缓存、校验失败、非法路径、取消后重试及并发初始化。
GitHub CI 会运行安卓单元测试。

发布前还需验证 APK 包含对应 assets，且签名验证通过。
Windows 上中文仓库路径的构建产物按根 Gradle 配置输出到磁盘根目录的
`agentflow-android-build/AgentFlow/app/outputs/apk/release`。

实机验收关注：无系统识别服务时首次断网转文字、拒绝/允许录音权限、
说完手动结束、取消后重试、切后台、直接发送和协作组语音。
自动化模型安装测试不能代替真实手机麦克风和识别准确度测试。

2026-09-20 本地验证：102 项单元测试全部通过，离线 Release 构建及 lint 通过。
最终 APK 为 77,378,433 字节，包内模型 SHA-256 与固定校验值一致，APK v2 签名有效。
本机未连接安卓设备，未进行物理麦克风实测。
